¿Por qué usar API CONSOLE V2?

◎

Zero Cost

Sin costos ocultos ni muros de pago. Pensado para bots de Discord/WhatsApp/Telegram, open source y prototipos rápidos.

◇

No Auth (Sin API Key)

Dispara peticiones HTTP directamente al endpoint y obtén tus datos al instante. Sin cabeceras obligatorios ni tokens que caducan.

▤

Auto-Discovery Registry

Cada archivo en src/routes/ se registra automáticamente en Express y aparece con su formulario en el Playground.

◈

JSON & SVG Media

Respuestas JSON estructuradas y generación dinámica de imágenes SVG en vivo: Brat, IQC, tarjetas, pósters y capturas.
