¿Por qué usar API CONSOLE V2?

💸

Zero Cost

Sin costos ocultos ni muros de pago. Pensado para proyectos personales, bots de Discord/WhatsApp/Telegram, open source y prototipos rápidos.

🔓

No Auth (Sin API Key)

Dispara peticiones HTTP directamente al endpoint y obtén tus datos al instante. Sin cabeceras obligatorias ni tokens que caducan.

⚡

Auto-Discovery Registry

Cada archivo que agregas en src/routes/ se registra automáticamente en Express y aparece con su formulario en el Playground.

🎨

JSON & Canvas Media

Soporta respuestas JSON estructuradas y generación dinámica de imágenes SVG/Canvas en vivo (tarjetas de bienvenida, Spotify, QR, avatares).

Es súper simple: abre cualquier archivo dentro de src/routes/ (por ejemplo src/routes/tools.js) o crea uno nuevo. Solo defines un objeto con name, path, method, params y la función handler(req, res). El motor src/registry.js lo detecta automáticamente y crea el formulario interactivo en /playground. También puedes usar el botón "+ Crear Endpoint" dentro del Playground.

El Playground consulta GET /api/endpoints al cargar, agrupa las rutas por categoría, permite filtrar por nombre o método HTTP, y al hacer clic en cualquier endpoint abre una consola de ejecución directa que mide los milisegundos de respuesta, muestra el código cURL / JS y renderiza JSON o imágenes en tiempo real.
